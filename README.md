# Simutrans TID

Simutrans Observer REST APIから鉄道編成の現在座標を読み込み、ローカルのCanvasへ表示する検証用Webアプリです。

## 起動

1. SimutransをREST APIポート`13355`で起動し、マップをロードします。
2. このディレクトリで`npm install`を実行します。
3. `npm run dev`を実行します。
4. ブラウザで`http://127.0.0.1:5173/`を開きます。

## コマンド

- `npm run dev`: ローカル開発サーバーを起動
- `npm test`: 自動テストを実行
- `npm run build`: 型チェックと本番ビルドを実行

API URLは`http://127.0.0.1:13355`固定です。データはブラウザから直接取得し、外部サーバーへの送信や位置履歴の保存は行いません。

## マップ操作

- PC: 左ドラッグまたはスクロールでマップ内を移動、`Ctrl`＋ホイールでカーソル位置を中心に拡大・縮小
- スマートフォン・タブレット: 1本指ドラッグで移動、2本指ピンチで中心位置を保って拡大・縮小
- 拡大率は25～400%。MAP枠外ではブラウザ標準のスクロール・ズームが動作します。
