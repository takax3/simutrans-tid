# Simutrans TID

Simutrans Observer REST APIから鉄道編成と駅の現在情報を読み込み、ローカルのCanvasへ表示する検証用Webアプリです。

## 起動

1. SimutransをREST APIポート`13355`で起動し、マップをロードします。
2. このディレクトリで`npm install`を実行します。
3. `npm run dev`を実行します。
4. ブラウザで`http://127.0.0.1:5173/`を開きます。

## コマンド

- `npm run dev`: ローカル開発サーバーを起動
- `npm test`: 自動テストを実行
- `npm run build`: 型チェックと本番ビルドを実行

API URLは`http://127.0.0.1:13355`固定です。データはブラウザから直接取得し、外部サーバーへの送信や位置履歴の保存は行いません。

## マップ操作

- PC: 左ドラッグまたはスクロールでマップ内を移動、`Ctrl`＋ホイールでカーソル位置を中心に拡大・縮小
- スマートフォン・タブレット: 1本指ドラッグで移動、2本指ピンチで中心位置を保って拡大・縮小
- 拡大率は25～400%。MAP枠外ではブラウザ標準のスクロール・ズームが動作します。
- 右上の`LAYERS`で概略路線、編成、駅を個別に表示・非表示にできます。
- 概略路線は各路線の停車駅・経由地点を運行順に直線で結んだもので、実際の線路形状とは異なります。
- 路線レイヤー配下の`駅に合わせる`は初期ONです。停車駅を示す点は駅APIの座標へ合わせ、経由地点はscheduleの座標を維持します。
- 操作欄の`編成種別`で表示するwaytypeを複数選択できます。選択は編成と概略路線の両方に適用されます。鉄道系は初期ON、自動車・船・飛行機は初期OFFで、現在存在しない種別は選択できません。
- 駅レイヤーには、選択中の交通種別に属する路線のscheduleに含まれる駅だけを表示します。
- 駅レイヤー配下の`全駅表示`をONにすると、交通種別の選択にかかわらずAPIから取得した全駅を表示します。初期値はOFFです。
- 駅マーカーにカーソルを合わせると、待機人数、収容人数、前月の到着・出発人数、座標、会社IDを確認できます。
